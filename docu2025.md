## Installation

### Prerequisites
- PHP 8.1 or higher
- Composer
- Node.js and npm
- MySQL/MariaDB
- Web server (Apache/Nginx)

### Setup Steps
1. Clone the repository
2. Install PHP dependencies: `composer install`
3. Install Node.js dependencies: `npm install`
4. Copy `.env.example` to `.env` and configure
5. Generate application key: `php artisan key:generate`
6. Run migrations: `php artisan migrate`
7. Seed the database: `php artisan db:seed`
8. Build assets: `npm run build`

## Troubleshooting

### Common Issues

#### 1. Route Not Found Errors
**Problem**: Routes returning 404 errors
**Solution**: 
- Clear route cache: `php artisan route:clear`
- Verify route exists: `php artisan route:list`
- Check route parameters match view calls

#### 2. Missing Language Parameter
**Problem**: "Missing required parameter for [Route: xxx]" errors
**Solution**: 
- Ensure all route calls include `app()->getLocale()` parameter
- Update view files to use proper route syntax
- Clear view cache after updates

#### 3. Asset Loading Issues
**Problem**: CSS/JS files not loading
**Solution**:
- Use `asset()` helper for all asset URLs
- Verify file paths are correct
- Check web server configuration

#### 4. Admin Panel Access
**Problem**: Cannot access admin panel
**Solution**:
- Ensure user is authenticated
- Check admin routes are properly registered
- Verify middleware is working correctly

### Debug Mode
To enable detailed error reporting:
```bash
# Set in .env file
APP_DEBUG=true
APP_ENV=local
```

### Log Files
Check Laravel logs for detailed error information:
```bash
tail -f storage/logs/laravel.log
```
